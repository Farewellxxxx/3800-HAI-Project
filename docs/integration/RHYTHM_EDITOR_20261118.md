# 拍手输入编辑收尾 · 2026-11-18

范围：E 盘个人完整版的录音 → 识别 → 编辑 → 试听 / MIDI / InputEvent。
本轮仅修改节奏网页和增加浏览器回归；未改识别器、Harness 或生成模型，未推送远端。

## 问题与修复

- 密集拍点原来至少占 14 px，且随整段长度使用固定比例，快拍会互相遮挡。现在点击区域随相邻拍距收窄，显示柱最大 8 px；支持整段 / 2 / 4 / 8 倍显示和横向滚动。缩放不改变拍点秒数、力度或事件 ID。
- 复现了编辑后原始录音仍继续播放：删除只会取消 MIDI 试听，源录音中的末拍仍能发声。编辑现在同时暂停原始录音；页面标明源录音保留录入时的声音，结果按钮标为“听当前 MIDI”。这是一种已确认的成因，不能证明用户上次听到的必然是同一路。
- 复现了删空拍点后无法导出 MIDI：后端已支持静音 MIDI，前端却提前返回。现在零拍点仍可试听 / 下载，保持原录音总时长；InputEvent 为 `no_onsets`，原识别快照保留。
